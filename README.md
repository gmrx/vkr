# Прогнозирование свойств композиционных материалов

Выпускная квалификационная работа по курсу «Наука о данных: профессиональный уровень (Data Science PRO)».

По свойствам компонентов композита считаются модуль упругости при растяжении и прочность при растяжении. Отдельно в ноутбуке обучается сеть, которая рекомендует соотношение матрица-наполнитель.

## Как запустить

Из этого каталога:

```bash
pip install -r requirements.txt
jupyter notebook issledovanie.ipynb
streamlit run app.py
```

Ноутбук читает файлы из `data/raw`, сохраняет рисунки в `figures` и модели в `models`. Приложение открывается после ноутбука: ему нужны файлы из `models`.
